### 修复清单（ArkTS 严格模式硬约束，无法关闭只能改代码）
配置类

ArkTS 语法类（arkts-no-* 规则）
- 对象字面量必须有声明类型：新增 `BgOption / NoiseOption / FriendRankItem` 接口（Types.ets）、`DayBar / InterruptRow`（Stats.ets）、`WeekCell / ForestCell`（Me.ets），替换所有 `{a: string} => void` 内联类型。

- 禁止动态 `import()` + 解构 + 对象展开：AppState 改用静态 import `BADGE_CATALOG` + `copyBadges()` 逐字段拷贝。
