# 青番 · 评审（REVIEW）

> 评审对象：当前 `qingfan` 鸿蒙工程代码。参照 `PRD / DESIGN / DATA_MODEL / ARCHITECTURE`。

## 1. 结论

- 功能覆盖 PRD FR-1~FR-11；页面 19 个全部注册；命令行构建通过。
- 与 Web / 小程序通过**同一套云函数账号与自习室数据**实现互通（房间号 UUID 一致）。
- 主要缺口集中在**后端能力**（成员真实昵称/专注时长统计）与**演示态功能**（短信/微信登录）。

## 4. 代码健康

- `AppState` 承担较多职责（状态 + 账号隔离 + 签到/连续 + 番茄→树），可后续拆分 `GrowthService` / `AuthState`。
- 多个弹窗为页面内 `@Builder`，样式重复；可抽 `Modal`/`PrimaryButton` 复用组件。
- `service/*` 结构清晰（通用 `CloudFnService` + 领域封装），新增接口成本低。

## 5. 验收建议（人工）

1. 游客：添加待办 → 开始专注 → 完成后番茄 +1；点 AI/统计/自习室 → 提示登录。
2. 注册（小程序端注册的号亦可）→ 登录 → 专注 → 退出 → 重登：番茄/时长/自习室恢复。
3. 创建自习室 → 复制房间号 → 在 Web/小程序用该号进入同一房间 → 双方留言可见、可回复。
4. 专注中提前退出 → 弹原因 → 选择后待办仍未完成、番茄未增加。
5. 切 4 套主题 + 3 种专注背景，颜色即时生效。
