# 青番 · DESIGN

> 视觉以 `design/index.html`（高保真原型）为准。本文档提炼设计令牌与组件规范，供 ArkTS 落地。

## 1. 设计基调

- 自然、克制、有呼吸感；标题用**衬线体**（`FONT_DISPLAY = 'serif'`），正文用系统无衬线体。
- 卡片化：白/浅底卡片 + 1px 描边 + 16~22 圆角；重点用渐变卡（自习室）。
- 主色为「叶子绿」，强调为「番茄红」，奖励为「金」。

## 3. 组件规范

- **卡片**：`surface` 底 + `line` 描边 + 圆角 16~22；阴影很轻（`rgba(0,0,0,0.05~0.12)`）。
- **胶囊按钮/标签**：`borderRadius(99)`，`leafSoft` 底 + `leafDeep` 字；选中态 `leaf` 底 + 白字。
- **主按钮**：`leaf` 底、白字、`borderRadius 14`、轻微阴影。
- **弹窗（Modal）**：居中卡片，宽 280~300，`surface` 底、圆角 22，遮罩 `rgba(30,40,26,0.42)`。
- **底部导航 TabBar**：高 64，`bar` 半透明底 + 顶部 1px 线；5→4 项（今日/自习室/统计/我的），选中 `leafDeep`。
- **圆环进度**：Canvas 绘制，轨道 11px；深色背景用白环，浅色背景用 `leafDeep` 环。
- **图标**：以 emoji 为主（🍅 🌿 🏆 🔥 📊 💬 🔒 等），保证跨主题一致。

## 4. 页面结构要点

- **今日 Home**：顶部日期+问候（长名字自适应缩小）+ 签到按钮 → 三栏概览（带分隔线）→ 今日挑战（进度条）→ AI 建议卡 → 今日待办（List，长按拖动、右滑删除）。
- **专注 Focus**：顶部任务/房间名 → 圆环倒计时 + 状态文案 → 时长胶囊 → 开始/暂停 → 专注背景色块（显示对应颜色）→ 白噪音 → 提前退出 / 🏆 排行（房间模式）。
- **自习室 StudyRoom**：顶栏（加入/创建）→「我的自习室」房间卡片（房名、房间号、人数、房主/有密码标签、💬留言、✕解散/退出、开始自习）→ 空态提示。
- **我的 Me**：未登录显示游客视图；登录后资料头 → 经验 → 签到 → 我的森林（网格）→ 本周打卡 → 徽章 → 累计数据 → 外观主题 → 桌面小组件 → 新手指引 → 设置 → 退出登录。
- **登录 Login**：品牌区（Logo 摇摆 + 叶子背景）→ 登录/注册切换 → 表单（手机号+密码 / 注册五项）→ 协议。

## 5. 多端适配（断点式响应布局）

- 目标设备：**手机**为主；`requiredDeviceType=phone`。
- 布局用 ArkUI 的自适应能力实现「随宽度伸缩」：
  - 宽度用百分比 / `layoutWeight`（列表项、三栏概览、TabBar 五等分）；
  - 弹窗用固定宽度（280~300）+ 居中；
  - 文字用 `maxLines + textOverflow + maxFontSize/minFontSize` 自适应（如首页问候语）。
- 桌面小组件通过 `form_config.json` 的 `supportDimensions`（2×2 / 2×4 / 4×4）与 `WidgetCard` 按尺寸分支渲染，实现「同一数据、不同尺寸」的适配。
- 高保真原型 `design/index.html` 以手机框（393×852）呈现；宽屏时原型会隐藏侧栏并自适应缩放。

## 6. 动效

- 引导页横向滑动轮播（`Swiper`，380ms `FastOutSlowIn`）。
- 圆点/胶囊选中态 300ms 缓动。
- 弹窗 `growIn`、列表 `fadeUp`、番茄完成 `confetti`/`floatY`（原型表达，ArkTS 侧以轻量动画近似）。

## 7. Web / 小程序端界面（与鸿蒙一致）

Web 与小程序**功能与视觉与鸿蒙端一致**：同一套设计令牌（4 主题）、同一套组件与页面结构。

- **设计令牌**：以 CSS 变量实现，与 `ThemeDef` 一一对应（青番绿 / 深夜墨 / 晨光暖 / 静谧蓝）；切换即时生效。
- **页面一一对应**：引导 / 登录注册 / 今日待办 / 专注计时 / 成长(我的) / 统计 / 自习室+房间 / 主题 / AI 助手。
- **组件一致**：卡片、胶囊按钮/标签、弹窗（创建/确认）、底部导航、圆环进度、专注背景三色（天空/晨雾/夕阳）。
- **自习室已实现**：`index.html`（自习室首页：我的自习室/自习动态/留言板/好友的自习室）、`login.html`（登录/注册）、`create.html`、`join.html`、`room.html`（房间详情：成员 + 交流/回复/点赞/删除）+ `styles.css`。
- 其余页面（今日/专注/成长/统计/主题/AI）按同一令牌与结构补齐，交互与字段对齐 `DATA_MODEL.md`。
- **Web 端为电脑端网页**：桌面浏览器框 + **左侧导航**（今日 / 自习室 / 统计 / 我的 + 主题切换 + 登录入口）+ 右侧主内容（内容区最大宽度居中）。
- **小程序**与 Web 同构（`wx.cloud`），样式与交互一致；身份用微信 OPENID，无需手机号即可进入自习室。
