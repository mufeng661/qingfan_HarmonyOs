# 青番 · 原型说明（design/）

## 文件

- `index.html` —— **鸿蒙端**高保真原型（React + Babel 单文件，直接双击用浏览器打开）。
- `web.html` —— **电脑端 Web** 原型：桌面浏览器框（1180×740）+ **左侧导航**（今日/自习室/时间轴/数据/我的 + 主题切换 + 登录入口）+ 右侧主内容（同 App 界面）。
- `miniprogram.html` —— **小程序端**原型：同一套界面，外壳为微信小程序框（右上角胶囊）。
  - 三者**功能与视觉完全一致**（三端功能一致），仅设备外壳不同；左侧品牌/模块/操作提示已按端标注。
  - 左侧为品牌/模块说明，中间为**手机框（393×852）**内的可交互原型，可切换页面、主题与专注背景。
  - 与正式 App 的视觉、交互一一对应，是 UI 验收基准。

## 页面与导航（与 App 一致）

- 底部导航 5 项：**今日 / 自习室 / 时间轴 / 数据 / 我的**。
- **时间轴**页：日/周/月切换，展示真实专注记录（起止 · 任务 · 时长）。
- **数据**页：累计专注卡、当日专注卡、**任务占比饼图**、**月度专注折线/面积图**（点右上 `🗓` 弹出**居中热力图**，含真实日历排布、`<1h` 标注）、打断原因分布、AI 洞察。
- **自习室**页：无房间时显示「加入 / 创建」卡片；有房间时显示**加入码**、正在专注中人数、当前排名、**成员专注卡片**（今日已专注 / 连续专注N天 / 共专注N天 / 累计分钟），房主长按成员可移出，留言（需当日达标）、分享、解散（10s 二次确认）；创建时可设**每日最低专注**。

## 多端适配与响应式布局

原型与 App 的适配策略一致：

1. **以手机为基准**：内容按 393 宽设计，App 端 `requiredDeviceType = phone`。
2. **原型侧的断点式响应**：
   - 视口宽度 ≤ 960px 时，隐藏左侧说明栏、仅保留手机框（`.stage-side { display: none }`）。
   - 手机框按窗口高度自动缩放（`scale`，0.5~1.05），保证整屏可见。
3. **App 侧的响应式（ArkUI）**：
   - 宽度用百分比 / `layoutWeight`：三栏概览、列表项、TabBar（5 等分）随屏宽伸缩；
   - 弹窗固定宽度（280~300）居中，避免小屏溢出；
   - 文字用 `maxLines + textOverflow + maxFontSize/minFontSize` 自适应（如首页问候语长名字）；
   - 桌面小组件按 `supportDimensions`（2×2 / 2×4 / 4×4）分支渲染，实现「同数据不同尺寸」的适配。
4. **主题适配**：4 套主题（青番绿 / 深夜墨 / 晨光暖 / 静谧蓝）以 CSS 变量 / `ThemeDef` 令牌切换，组件不写死颜色。

## 打开方式

- 浏览器直接打开 `design/index.html`（鸿蒙）/ `web.html`（Web）/ `miniprogram.html`（小程序）；
- 顶部可切换主题；进入「专注」页可切换「天空 / 晨雾 / 夕阳」背景（色块显示对应颜色）。
